# 数据目录说明

本目录存放分析所需的原始数据，**不纳入版本控制**（总量约 780 MB）。

## 目录约定

```
data/
└── 中文版/
    ├── 用户基础信息.csv
    ├── 用户行为日表.csv
    ├── 直播间日统计.csv
    ├── 主播基础信息.csv
    ├── 送礼交易明细.csv
    ├── AB实验曝光表.csv
    └── 公会信息.csv
```

脚本中的 `DATA_DIR` 默认指向 `data/中文版`，文件名需与上表一致。

## 数据来源

`XXX Live` 为课程提供的脱敏业务数据集（平台覆盖 150+ 国家，MAU 2.72 亿，2025 年直播业务收入 15.3 亿美元）。受课程授权限制，原始数据不随仓库分发。

各表的字段含义见 `docs/数据集说明.txt` 与 `docs/数据字典.xlsx`。

## 复现时如何准备

若你持有同源数据集，将 7 个 CSV 放入 `data/中文版/` 即可直接运行 `code/` 下的脚本。字段类型与缺失情况见 `docs/数据集说明.txt`。

若仅想了解分析方法，可跳过数据准备，直接阅读 `reports/` 下的完整报告与 `code/output/` 下的图表结果。
